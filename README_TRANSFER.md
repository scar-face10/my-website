# Angels Display Solutions — portable project

This archive contains the latest website source, HTML routes, JavaScript, CSS, assets, project configuration, and server runtime.

## Run in another IDE

1. Open the `angelsdisplay` folder.
2. Confirm Node.js is installed.
3. Run `npm run dev`.
4. Open `http://localhost:3000/` in a browser.
5. The gallery route is available at `http://localhost:3000/gallery.html`.

The project has no committed dependency directory; install dependencies with `npm install` if dependencies are added later. The Git history directory is intentionally not included in this portable source archive.
